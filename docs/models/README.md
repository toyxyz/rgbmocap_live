# RGB MoCap Live model guides

- [PEAR · Live](PEAR.md) supports one or more views, body and finger tracking
  and optional Foot Lock.
- [InstantHMR · Live](INSTANTHMR.md) supports one or more views and an
  MHR-derived body and finger skeleton.

Both models share the YOLOv8s detector and optional camera files. See the
[Live user guide](../USER_GUIDE.md).
